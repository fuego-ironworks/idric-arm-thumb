# Books and paper notes

This directory is for durable technical reading notes that support the Idriç ARM/Thumb work without pretending that every paper is an implementation dependency.

## Collections

- [3SUM / APSP 2026 breakthrough](3sum-apsp-2026/README.md) — Alman–Vassilevska Williams, the thin wanted-entry matrix-product algorithm, its 3SUM/APSP reduction chain, direct cited-paper notes, and a reproducible one-level bibliography spider.

The notes distinguish three things:

1. **paper claims** — what a source actually proves;
2. **implementation relevance** — what is useful as an Idriç/ARM/Thumb workload or compiler idea;
3. **speculation** — possible experiments that are not claims of the source.

Do not treat a citation-context note as a substitute for reading the paper when a proof detail or exact bound matters.
